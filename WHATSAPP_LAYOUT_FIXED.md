  - Text "Join Groups"

- **Create Group Button**:
  - WhatsApp dark green color (#075E54)
  - Ultra-compact size (5px 7px padding)

### 3. **Ultra-Compact Chat Header**
- **Padding reduced**: From 16px 20px to 8px 12px for WhatsApp
- **Maximum space efficiency** layout

### 4. **Optimized Message Input Area**
